セットアップと使い方

使い方

  • 右側のフォームに名前・座標を入れて「追加」
  • マップ上の点をクリックで選択 → 編集・削除
  • マップをドラッグでスクロール、ホイールでズーム
  • マップ上を ダブルクリック でその座標に新規追加
  • ピンを ドラッグ で座標を直接修正できます (移動後にFirebaseへ保存)
  • 変更は自動でFirebaseに保存され全員に同期

ツール

  • 📏 距離計測: 2点クリックで直線距離を表示。OWではネザー換算 (÷8) も表示
  • 🛤️ ルート作成: クリックで点を追加、Enter/完了で保存。鉄道や道筋の可視化に
  • Esc キーで現在のツールを終了

検索 / フィルター

サイドバー上部の検索ボックスで施設名検索。カテゴリのチップでON/OFF切替できます。条件外のピンはマップ上で薄く表示されます。

ディメンション切替

上部のタブで「オーバーワールド / ネザー / エンド」を切り替え。施設・ルートはディメンションごとに別々に保存されます。

💡 ネザー座標の換算: オーバーワールド座標 ÷ 8 ≒ ネザー座標 (Y座標はそのまま)

カテゴリを「ポータル」にすると対応ディメンションでの座標を自動提案します。「リンク先を追加」で逆側にも自動作成。

バイオーム背景

上部の 🗺️ ボタンから設定。Chunkbase Biome Finder でシード 5492515056883084598 を入力 → 表示範囲のPNGを保存 → 画像URLと座標範囲を入力すると背景に重なります。

データ管理

📁 ボタンからJSONエクスポート/インポート。Firebase 障害時のバックアップや、別の部屋へのコピーに使えます。

部屋を分ける

URLの末尾に #room=部屋名 を付けると別マップになります。例: ...index.html#room=mansion

初回ホスト側セットアップ (1回のみ)

  1. Firebase Console でプロジェクト作成
  2. 左メニューの「Realtime Database」→ 作成 (テストモードでOK)
  3. プロジェクト設定 → ウェブアプリ追加 → firebaseConfig をコピー
  4. このHTMLの先頭の const firebaseConfig = {…} を貼り替え
  5. HTMLを GitHub Pages / Netlify / Firebase Hosting 等に配置
  6. そのURLをDiscordで共有 → 友人は開くだけで使えます

Realtime Database のセキュリティルール例

{
  "rules": {
    ".read": true,
    ".write": true
  }
}

⚠ 上記は誰でも書き込み可能です。URLが流出すると荒らされる可能性があります。心配なら Firebase Authentication の匿名認証 + auth != null ルールに変更してください。
